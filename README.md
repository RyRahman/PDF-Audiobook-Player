# PDF Audiobook Player

Turn PDF books into an audiobook-style listening experience directly in your browser.

## Live App

https://ryrahman.github.io/pdf-audiobook-player/

## Features

- Upload PDF books directly from your device
- Automatically displays the first PDF page as the book cover
- Reads PDF text aloud using your device's built-in voices
- Play and pause controls
- Previous and next chapter controls
- Skip forward and backward
- Adjustable reading speed
- Adjustable voice pitch
- Voice selection
- Reading progress control
- PDF bookmark and chapter detection when available
- Automatic chapter fallback when bookmarks are unavailable
- Works on desktop and mobile browsers
- PDFs are processed locally in your browser and are not uploaded to a server

## How to Use

1. Open the app.
2. Upload or drag and drop a PDF book.
3. Wait for the PDF to load and process.
4. Select your preferred voice.
5. Adjust the speed or pitch if desired.
6. Press Play to start listening.
7. Use the chapter, skip, and progress controls to move through the book.

## GitHub Pages Deployment

This project can be hosted directly with GitHub Pages.

1. Create a GitHub repository named `pdf-audiobook-player`.
2. Upload `index.html` and `README.md`.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/root`.
7. Click **Save**.

Your app should then be available at:

https://ryrahman.github.io/pdf-audiobook-player/

## Privacy

PDF files are processed in your browser. The app does not intentionally upload your PDF books to a server.

## Mobile Note

Browser text-to-speech behavior varies by device. Some mobile browsers may pause or stop speech when the phone is locked or the browser is placed in the background.
